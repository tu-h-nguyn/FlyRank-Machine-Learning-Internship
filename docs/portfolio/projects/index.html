01
FlagshipScientific MLThesis

Python · PyTorch · NumPy · pytest · LaTeX

Theoretical Foundations of Neural Networks and PINNs

Physics-informed neural networks degrade on problems with a small length scale. The thesis asks why, and at which level: approximation, optimisation, or the stability of the differential problem itself.

Method

Feed-forward networks analysed through derivatives with respect to the input, giving explicit Jacobian and Hessian recurrences · backpropagation, forward- and reverse-mode differentiation derived · gradient pathology, spectral bias and a residual-to-error stability bound, each tied to one experiment.

Implementation

A PINN written on torch.autograd with no PINN library: 885 lines across the core module and six experiment scripts; derivatives of any order by nested autograd; Adam, then L-BFGS. 20 unit tests check the primitives against closed-form mathematics; 39 checks re-derive every published number in CI.

Result

Six experiments with pass/fail criteria fixed before running. Under ReLU the residual objective is exactly stationary — its gradient is 0.0, not small. The differential operator reverses spectral bias, contradicting the thesis's own chapter 4, which the text then retracts. Burgers at small viscosity is reported as a negative result.

Role

The theory and proofs are mine. The test suite, verification script and CI were added later with AI assistance; the repository says which commits.

02
Machine LearningPaper

Python · scikit-learn · pandas · NumPy · Matplotlib

Search-Ranking Refresh Queue

An editorial team can review about 50 pages a week out of 18,000. The useful question is not which pages are bad but which to open first — an ordering problem, not a threshold one.

Method

Leakage audit · rule baseline before any model · logistic regression and random forest · GroupKFold(5) by client · precision@K at the team's real capacity · permutation importance · stability across five client holdouts.

Implementation

  • Started from FlyRank's internship starter repository: an anonymised 30,000-row dataset and a skeleton script — no framing, modelling or evaluation.
  • Defined the label: a >20% impressions drop in the last of three exact 30-day windows cut from one 90-day snapshot.
  • Removed every window-spanning column, including one I had used in an earlier week; engineered 24 decision-time features.
  • One script reproduces the pipeline and writes an 18,010-row action queue with reason codes, suggested action and confidence.

Result

Logistic regression on honest features: PR-AUC 0.718, precision@50 0.88 — against 0.668 / 0.74 for the rule baseline and 0.617 for random ordering, on a 0.62 base rate. Stable across client holdouts (PR-AUC 0.668 ± 0.026). An earlier rule of mine scored only 12 of 18,010 pages above zero (ROC-AUC 0.500); the paper reports it as a failure.

03
QuantitativeTime Series

Python · pandas · scikit-learn · XGBoost · pytest · ruff

AI Quant Trading Research Lab

Does a leakage-aware machine-learning signal add value out of sample, after trading costs, relative to simple trading rules? The harness is built so that the answer is allowed to be no.

Method

Chronological walk-forward refits from independent estimator clones, with an embargo for forward-horizon labels · buy-and-hold, momentum and moving-average baselines against logistic regression and XGBoost on SPY, QQQ, IWM, TLT and GLD · costs charged on turnover · moving-block bootstrap for dependent daily returns.

Implementation

Data, features, models, portfolio construction, risk, execution costs, validation and reporting kept in separate modules, so an experiment can change without silently changing the backtest. Long-only minimum-variance and risk-parity weights from trailing observations, lagged before returns apply; volatility targeting and drawdown guardrails. Each run writes a machine-readable record of its configuration and source commit.

Result

A research harness, not a strategy. No returns are quoted here: none are committed to the repository — its research workflow regenerates the report, and the design treats an ML signal that loses to a baseline as a valid outcome.

Research software. Not investment advice, not intended for live trading.

Machine LearningRetrieval

Python · sentence-transformers · Chroma · pytest · mypy

Enterprise Hybrid RAG

Answer questions from PDF, DOCX and Markdown with citations that resolve to a page — and know which retriever to trust for which kind of question.

Method

No RAG framework. BM25 and dense retrieval built from the same chunk list in one pass · reciprocal-rank fusion · cross-encoder reranking · a confidence gate that abstains · citations resolved to the page, invalid ones dropped.

Implementation

Loaders that keep page and section; a sentence-aligned chunker; Chroma (384-d cosine) and BM25 Okapi indexes; all-MiniLM-L6-v2 and ms-marco-MiniLM-L-6-v2. A benchmark of 50 questions over 22 documents, regenerated by CI on every pull request.

Result

Recall@1 0.795 for hybrid + reranker, against 0.585 dense-only and 0.643 BM25. By question type the two retrievers fail in opposite directions — BM25 1.00 on keyword questions and 0.11 on paraphrase, the dense encoder 0.43 and 0.44 — and the reranked hybrid holds both ceilings. The cost: about 694 ms per query, against 0.75 ms for BM25.

05
Numerical AnalysisPDE

Python · NumPy · Matplotlib · LaTeX · GitHub Actions

Sharp CFL Analysis — FEM for the Wave Equation

Courses quote Δt ≤ h/c as the stability limit for explicit time-stepping on the wave equation. With a consistent mass matrix that bound is wrong, and a scheme built on it diverges — quietly, because the unstable mode is the one the initial data barely excites.

Method

Closed-form spectrum of the stiffness/mass pair (S, T) · a necessary and sufficient stability condition · Ritz projection for the convergence proof · Thomas algorithm, O(N) per step · four numerical experiments.

Implementation

A reproduction harness recomputes all four report tables from source and fails on any mismatch with the published PDF, in CI on every push. It found a real gap: the published growth() listing could not generate the report's own Table 3. Report and web figures are rendered from one set of computed arrays, so they cannot drift.

Result

Two CFL constants where the literature usually states one: Δt < h/(c√3) with the consistent mass matrix, Δt < h/c with the lumped one. The measured threshold matches the analytic θ* to four significant figures; convergence is 2.00 in L² and 1.00 in H¹ across six refinements.

Role

Two-person coursework report; the verification, the fix and the figure pipeline are mine.

06
Numerical AnalysisConservation Laws

Python · NumPy · pytest · mypy · GitHub Actions · LaTeX

Finite-Volume Solver for the 1D Euler Equations

The Euler equations grow shocks, contacts and rarefaction fans from smooth data. A scheme that looks convincing on a smooth problem can be quietly wrong at a discontinuity — so the question is what it is measured against.

Method

An exact Riemann solver as ground truth, and everything measured against it: four numerical fluxes (Lax–Friedrichs, Rusanov, HLL, HLLC) · MUSCL reconstruction with four TVD limiters and a positivity safeguard · three SSP time integrators.

Implementation

A Python package with a CLI and a library API, and one command from source to every table and figure it publishes. 133 tests, 98% coverage, mypy clean, CI on every push, MIT.

Result

On Sod's shock tube (N = 200, CFL 0.4, t = 0.2) the L¹ density error falls from 3.274e−02 for Lax–Friedrichs to 4.446e−03 for MUSCL–minmod — 7.4× smaller on the same grid. A grid-convergence study confirms the schemes reach their design order.

Role

The repository is mine: package layout, exact solver, tests, CI. The report is four-person coursework (Nông Thanh Toàn, Nguyễn Hoàng Tú, Lê Minh Tuấn Kiệt, Đặng Kim Bảng), Chuyên đề giải tích số, 2025.

07
Numerical AnalysisODE

Python · NumPy · pytest · ruff · GitHub Actions · LaTeX

Linear Multistep Methods — Dahlquist, Derived Not Quoted

Courses state the equivalence theorem — a linear multistep method converges if and only if it is consistent and zero-stable — and the BDF barrier k ≤ 6 as facts to memorise. Both can be checked by machine.

Method

A library that hard-codes no conclusions. Given the coefficients (αj, βj) it derives the order, the error constant, the roots of the characteristic polynomial, zero-stability and the absolute-stability region.

Implementation

Each textbook claim is a test assertion the build must satisfy: 93 tests, CI across Python 3.10–3.13, MIT. The 63-page report and 50-slide deck are in the repository.

Result

Measured order agrees with theory to within 0.12 across eight zero-stable methods. BDF loses zero-stability exactly at k = 7 (max|zi| = 1.0222) — the barrier falls out of the polynomial roots rather than being assumed. A consistent order-3 method that is not zero-stable reaches error 10³⁷ by t = 6.

Role

The library and its test suite are mine. The report is three-person coursework (L. T. Nhân, D. T. H. Yến, N. H. Tú).

08
OptimisationConvex Analysis

MATLAB · Octave · Python · LaTeX

Inexact and Accelerated Proximal Point Algorithms

The accelerated proximal point method assumes each inner subproblem is solved exactly. In practice it never is — so how much inexactness does the O(1/k²) rate survive?

Method

A synthetic LASSO (n = 80, m = 30, sparsity 8) through the inexact accelerated method and the classical proximal point method, under five inner-accuracy schedules — fixed budgets of 1 and 4 inner steps, log k, √k and exact — traced against the O(1/k) and O(1/k²) rates.

Implementation

MATLAB and Python experiments; one build generates the report, slides and presentation script from a single set of sources. The report's convergence bound is checked by CI at every outer step: 90 checks, mutation-tested — 10 planted bugs, all 10 caught.

Result

By k = 40 the √k schedule sits 54× below the classical method and exact solves 198×, while fixed budgets of 1 and 4 steps stall at 3×10⁻² and 1.4×10⁻⁴. The bound: 0 violations in 121 outer steps for all five schedules.

Role

The repository is mine. The written work is group coursework (Nhóm 10), optimisation topic.
